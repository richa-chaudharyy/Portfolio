I’m Richa Chaudhary, a BS Data Science and Applications student at IIT Madras, graduating in 2029. I’m interested in software development, data engineering, analytics, databases and AI/ML, and I enjoy understanding how complete applications work from the interface to the data behind them.

I learn best by building. My projects include a Flask-based Trekking Management Application, a full-stack Airbnb clone using the MERN stack, a Django social media application, a portfolio website, and several frontend projects built while learning web development.

Through these projects, I’ve worked with authentication, role-based access, CRUD operations, database design, form validation, responsive interfaces, debugging and version control. I’m currently strengthening my data structures and algorithms, core computer science, analytics and project-development skills.

I’m especially interested in work where software and data come together — building useful applications, working with structured data, and gradually developing a stronger understanding of reliable systems and intelligent data-driven products.
